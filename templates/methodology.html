EQUAL WEIGHT FOR EVERY LINK

Resource accessibility, explained.

The score describes availability of extracted links. It does not run experiments or establish reproducibility.

Equal-link scoring · v2.0

Score = accessible unique URLs ÷ total extracted unique URLs × 100.

Each URL counts once and has equal weight. Categories, including Other, are labels only. A paper is not penalized for lacking a dataset link, code link, or any other category.

For example, if 8 of 10 links are accessible, the score is 80/100. If a paper has only 3 code links and all are accessible, it scores 100/100.

Only successful HTTP 2xx responses count as verified accessible. Restricted, unresolved, and blocked links remain in the total, but are not confirmed missing.

If no links were checked, the report shows Not scored rather than zero. Scores are rounded to the nearest whole number.

Extraction and coverage

We extract embedded PDF hyperlinks and HTTP/HTTPS URLs from readable PDF text and abstracts, preserving nearby evidence and page numbers. Repeated URLs are counted once.

All extracted URLs are checked without prioritizing categories. Categories can be corrected without changing the score. Extracted links may include citations and general websites, so review their evidence.

PDFs are limited to 20 MB and 300 pages, with extraction limits for oversized text and excessive links. Image-only PDFs need OCR, which is not included.

If a remote PDF cannot be retrieved, the report uses abstract links and is marked partial. Its score describes that limited sample, not the full paper. Older reports that checked only a subset should be rechecked.

Accessibility statuses

  • Accessible: HTTP 2xx; content completeness is not audited.
  • Missing: HTTP 404 or 410.
  • Restricted: HTTP 401, 403, or 429; login, bot protection, or rate limits may apply.
  • Unresolved: DNS, TLS, timeout, redirect, or unexpected response errors.
  • Blocked: private, local, reserved, or otherwise disallowed destinations.

Checks retain UTC timestamps. Rechecking updates the availability snapshot. A high score does not demonstrate that a paper's experiments can be reproduced.
