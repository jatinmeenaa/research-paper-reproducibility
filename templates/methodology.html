Score = 100 × weights of applicable categories with an accessible link ÷ weights of all applicable categories.

A category receives its full weight when at least one detected link returns a successful HTTP status. Other links receive no points. Excluded categories contribute to neither numerator nor denominator.

Example: code and dataset links are accessible, while documentation and supplementary material are not detected. With all categories applicable, the score is 70/100. If only code and datasets are applicable, the score is 100/100. Always compare category selections alongside scores.

How resources are found

We read embedded PDF hyperlinks and HTTP/HTTPS URLs in PDF text and abstracts. Domain names, URL paths, and nearby text suggest a category. The report preserves page numbers and text evidence so you can check the classification.

These heuristics can include references to other papers or misclassify a general repository. You can correct categories, including marking unrelated links as “Other,” which contributes no points. Image-only PDFs need OCR and may have incomplete coverage.

What accessibility means

  • Accessible: HTTP 2xx. The URL responds publicly; content completeness is unknown.
  • Missing: HTTP 404 or 410 at the time of checking.
  • Restricted: HTTP 401, 403, or 429. Login, bot protection, or rate limits may apply.
  • Unresolved: network/TLS errors, timeouts, unexpected responses, or unsuccessful checks.
  • Blocked: a local, private, reserved, or otherwise disallowed destination.

Restricted and unresolved results mean uncertainty, not confirmed absence. Each report records a UTC timestamp and can be refreshed.

Coverage and limits

Uploads and PDF downloads are limited to 20 MB and 300 pages. At most 60 links are checked per report, prioritizing recognized resource categories. Redirects are bounded and each destination is checked against public-network rules. Checks use HEAD with a small GET fallback when HEAD is unsupported.

When a remote PDF cannot be retrieved, analysis falls back to links in the abstract and clearly labels the report as partial. No code, full datasets, supplementary contents, or external web pages are executed or deeply inspected.

Your local research workspace

Papers, reports, and uploaded PDFs are saved in the local data directory. Discovery contacts arXiv or Semantic Scholar; availability checks contact linked public hosts. This application is designed as a personal, single-process tool without user accounts.

Search uses the arXiv API and Semantic Scholar Academic Graph API . Provider limits and outages may affect results. The library and existing reports remain available offline.
